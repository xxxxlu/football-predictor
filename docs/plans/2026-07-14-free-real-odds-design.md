# 免费真实赔率同步设计

## 目标

在不伪造赔率、不超出免费额度的前提下，为当前世界杯赛程提供真实的赛前胜平负（1X2）赔率，并继续保留 OpenLigaDB 作为赛程与赛果来源。

## 方案

- OpenLigaDB：同步 2026 世界杯赛程和赛果，不需要密钥。
- The Odds API：只请求 `soccer_fifa_world_cup` 的 `eu` 区域、`h2h` 市场和 decimal 格式赔率。
- 每次响应选择第一个同时包含主胜、平局、客胜的真实 bookmaker，并保留其名称和更新时间；不平均、不补造、不把平台固定倍率冒充真实赔率。
- 用中文队名和开球时间把赔率事件匹配到 OpenLigaDB fixture；无法可靠匹配的数据直接跳过。
- 真实赔率落入 PostgreSQL 产品缓存，页面读取和提交预测均不直接请求上游。

## 免费额度控制

- 数据库中任一当前世界杯真实赔率在 12 小时内更新过时，本轮完全跳过 The Odds API。
- 只有缓存过期时才发出一次赛事级请求；一次请求返回该赛事的全部近期比赛。
- 正常上限约 2 次/天、60 次/月，显著低于 500 credits/月；页面访问、刷新按钮和多实例冷启动共享数据库节流结果。
- The Odds API 失败或没有可匹配赔率时继续展示赛程，但不伪造真实赔率；已有缓存仍可按 13 小时有效窗口使用。

## 验证

- 单元测试覆盖响应映射、真实 bookmaker 选择、队名/时间匹配、12 小时缓存节流和平台倍率回退。
- 域测试覆盖 The Odds API 赔率的 13 小时提交有效期。
- 运行相关测试、typecheck、lint 和 production build 后再提交推送。
